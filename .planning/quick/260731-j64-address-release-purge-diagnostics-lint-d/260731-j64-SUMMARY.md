## Decisions Made

- Code 1012 alone is not enough to select permission guidance; the response must also contain the `token lacks cache_purge` message.
- Remote response bodies are logged only behind a fixed prefix after `head -c 512` and `tr '\r\n' '  '`, never inside the GitHub warning annotation.
- ShellCheck and yamllint versions remain visible diagnostics, but only actionlint is pinned because runner package equality was the brittle part of the prior contract.
