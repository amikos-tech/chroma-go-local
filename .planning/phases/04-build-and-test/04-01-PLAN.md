In `backup.go`, add inline `//nolint:staticcheck` directives to the two deprecated type alias lines. Change lines 7-8 from:
```go
type ServerBackupOptions = runtime.ServerBackupOptions

```
to:
```go
type ServerBackupOptions = runtime.ServerBackupOptions   //nolint:staticcheck // re-export deprecated type for backward compatibility
```

These two types have `// Deprecated:` doc comments in `internal/runtime/backup.go`, causing `staticcheck SA1019` to flag the facade re-export. The nolint directive suppresses this because the facade MUST re-export all public symbols for backward compatibility, including deprecated ones.

Do NOT modify any other lines in backup.go. Per D-15, no lint exclusion rules are added to .golangci.yml for this.
