   - Start embedded session, call `session.compactCollection(new CompactCollectionRequest.Builder("nonexistent").build())`, `assertThrows(ChromaException.class, ...)`.
   - Verifies EMNT-02 error path.

5. **`embeddedPruneWalAllDryRunSmoke(@TempDir Path persistDir)`**
   - Start embedded session (empty DB), call `WALPruneResult result = session.pruneAllWAL(new WALPruneOptions.Builder().dryRun(true).build())`.
   - Assert: `assertNotNull(result)`, `assertTrue(result.dryRun())`, `assertEquals(0, result.collectionCount())`.
   - Verifies EMNT-03: pruneAllWAL dry-run on empty DB returns valid result.

   - Start embedded session, call `session.pruneCollectionWAL("nonexistent", WALPruneOptions.defaults("nonexistent"))`, `assertThrows(ChromaException.class, ...)`.
   - Verifies EMNT-03 error path.

     ```java
     assertThrows(IllegalStateException.class,

     ```
